# Provider 最小权限授权说明

适用范围：客户为云安全组、iptables 代理、EDR 或自定义 webhook provider 授权真实响应权限时使用。

## 强制前置声明

- 默认运行基线必须为 `DRY_RUN=true`。
- Provider 授权完成不代表真实响应启用，真实响应仍需要单独审批。
- 未完成恢复演练不得启用 `DRY_RUN=false`。
- 出现误封时，优先切回 `DRY_RUN=true` 并撤销 `REAL_ENFORCEMENT_GATE`，再执行解封或释放。

## 云安全组最小权限

允许权限：

- 查询指定安全组或防火墙规则。
- 仅向指定安全组添加 Guardian 标识的 deny/drop 规则。
- 仅删除 Guardian 创建且带有审批、TTL、动作标识的规则。

禁止权限：

- 修改非目标安全组。
- 修改入站放行规则。
- 修改路由表、IAM、实例生命周期、负载均衡、DNS。
- 删除客户手工创建或非 Guardian 标识的规则。

## EDR 最小权限

允许权限：

- 查询目标主机状态。
- 隔离客户确认的测试或生产目标主机。
- 释放由本次审批关联的隔离动作。

禁止权限：

- 隔离 EDR 管控节点、域控、堡垒机、日志平台、备份节点。
- 删除 EDR Agent、关闭 EDR 策略、修改全局安全策略。
- 对未确认 `host_id` 的 IP 直接执行隔离。
