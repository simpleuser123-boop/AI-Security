# 误封恢复演练模板

适用范围：真实响应启用前或启用后定期验证误封止血、解封、加白、审计和复盘能力。

## 强制前置声明

- 演练开始前默认 `DRY_RUN=true`。
- 真实响应演练窗口需要单独审批，审批通过后才可临时设置 `DRY_RUN=false`。
- 未完成本演练并通过验收，不得启用生产真实响应。
- 演练或生产出现误封时，优先切回 `DRY_RUN=true` 并撤销 `REAL_ENFORCEMENT_GATE`。

## 演练步骤

| 步骤 | 操作 | 预期结果 | 实际结果 | 时间 | 证据 |
|------|------|----------|----------|------|------|
| 1 | 确认 `DRY_RUN=true`，`REAL_ENFORCEMENT_GATE` 为空 | 进入安全基线 |  |  |  |
| 2 | 执行 dry-run 封禁/隔离 | 只记录计划和审计，不产生真实变更 |  |  |  |
| 3 | 四类 gate 和审批确认 | 满足启用条件 |  |  |  |
| 4 | 临时设置 `DRY_RUN=false` 和 `REAL_ENFORCEMENT_GATE=real-enforcement` | 仅在窗口内生效 |  |  |  |
| 5 | 对测试目标执行真实响应 | provider 侧状态生效且带 TTL |  |  |  |
| 6 | 模拟误封处置：切回 `DRY_RUN=true` 并撤销 gate | 新真实动作停止 |  |  |  |
| 7 | 执行手工解封、rollback 或 EDR release | 测试目标恢复访问 |  |  |  |
| 8 | 加入或修正白名单 | readiness 白名单项通过 |  |  |  |
| 9 | 归档审计证据 | action、task、audit、provider 日志完整 |  |  |  |
| 10 | 复盘并确认是否允许后续启用 | 未完成复盘不得再次启用真实响应 |  |  |  |
