# AI-Security-Guardian 下一步建议

## 1. 总体建议

建议先做 Phase A 的“商业化地基冲刺”，目标不是堆新功能，而是让单企业私有化版本可稳定交付、可升级、可验收、可回滚。随后尽早启动 Phase B 的租户改造，因为 `tenant_id` 是架构级变化，越晚做，后续 SaaS 化成本越高。

## 2. 最近 2 周建议

### 研发侧

- 引入 Alembic/Flask-Migrate，建立正式迁移目录。
- 为现有核心表生成初始迁移：`alerts`、`alert_histories`、`rules`、`iocs`、`settings`、`banned_ips`、`response_actions`、`response_schedule_tasks`、`audit_events`、`model_versions`。
- 将以下命令纳入 CI：
  - `python -m pytest -q`
  - `python scripts/check_production_readiness.py`（私有化 Beta gate，允许 `DRY_RUN=true`）
  - `python scripts/check_production_readiness.py --gate real-enforcement`（仅真实封禁上线前执行）
  - `python scripts/verify_v1.py`
  - `python scripts/benchmark_http.py`
- 梳理私有化安装流程，形成一键初始化脚本。
- 将响应动作默认保持 dry-run，补充审批、白名单和误封恢复说明。

### 产品侧

- 定义首批私有化客户交付范围。
- 明确单企业版本 SKU：基础版、专业版、企业版。
- 梳理告警、响应、审计、报表的演示故事线。
- 明确哪些能力作为销售亮点，哪些能力只作为技术底座。

### 安全合规侧

- 固化上线证据清单。
- 固化审计事件类型。
- 制定数据保留、备份、恢复、误封恢复模板。

## 3. 最近 1 个月建议

### 私有化 Beta

- 完成私有化部署包。
- 完成 PostgreSQL、Redis、Nginx TLS、模型目录、审计日志的标准化部署。
- 完成恢复演练。
- 完成 1 个内网试点环境连续运行。

### 多租户设计

- 设计 Tenant、Organization、User、Membership、Role、APIKey 模型。
- 明确所有业务表的 `tenant_id` 增加策略。
- 设计租户上下文传递方式：
  - JWT claim。
  - API Key。
  - Redis Stream message。
  - 审计事件。
  - 报表导出。

### 商业化设计

- 定义套餐维度：
  - 用户数。
  - 告警保留期。
  - 规则数。
  - IOC 数。
  - 通知通道。
  - API 调用量。
  - 响应动作数量。
- 设计 UsageMeter 数据模型。
- 定义 License 校验策略。

## 4. 最近 1 个季度建议

### 产品化交付

- 私有化 GA。
- 完成至少 1-2 个试点客户闭环。
- 建立标准交付报价、部署手册、验收清单、运维 SLA。

### 多租户 Alpha

- 完成核心数据租户隔离。
- 完成租户级 RBAC。
- 完成租户级规则、IOC、通知配置。
- 完成越权测试。

### SaaS Beta 准备

- 完成套餐、配额、用量计量。
- 建立 SaaS 运维后台。
- 建立状态页和值班流程。

| 产品负责人 | 定义 SKU、验收口径、客户价值、交付边界 |
| 技术负责人 | 架构演进、租户隔离、发布治理、技术债优先级 |

| 合规/交付 | 合规证据、交付文档、客户验收、演练记录 |

## 6. 推荐决策点

### 需要立即决策

- 私有化优先还是 SaaS 优先。
- 首批客户部署环境：客户内网、专有云，还是厂商托管。
- 是否允许自动封禁默认开启。
- 是否把多租户改造作为下一阶段主线。

### 建议默认选择

- 先私有化，后 SaaS。
- 自动响应默认 dry-run；私有化 Beta readiness 允许 `DRY_RUN=true`，真实封禁需审批、审计、回滚、解封、复盘并通过单独 gate。
- 多租户设计尽快进入主干。
- 合规证据从 Phase A 开始沉淀。

## 8. 成功判定

近期成功不以“功能数量”衡量，而以以下结果衡量：

- 能稳定部署到一个全新客户环境。
- 能升级、回滚、恢复。
- 能解释每条告警、每次响应、每次配置变更。
- 能证明数据不会因重启或升级丢失。
- 能为多租户和 SaaS 留好架构入口。
